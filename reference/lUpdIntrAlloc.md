# Update between ISA allocation ratio

Functions and rules for between ISA allocation ratio update of class
lUpdIntrAlloc

## Usage

``` r
new_lUpdIntrAlloc(
  fnUpdIntrAlloc = function(lPltfTrial, lAddArgs) {
 },
  lAddArgs = list()
)

validate_lUpdIntrAlloc(x)

lUpdIntrAlloc()
```

## Arguments

- fnUpdIntrAlloc:

  Function that updates allocation ratios between ISAs

- lAddArgs:

  Further arguments used in fnUpdIntrAlloc

- x:

  An object of class lUpdIntrAlloc

``` r
if (FALSE) { # \dontrun{

} # }
```
