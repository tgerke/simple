# Within ISA allocation ratio

Functions and rules for within ISA allocation ratio of class lAllocArm

## Usage

``` r
new_lAllocArm(
  fnAllocArm = function(lPltfTrial, lAddArgs) {
 },
  lAddArgs = list()
)

validate_lAllocArm(x)

lAllocArm()
```

## Arguments

- fnAllocArm:

  Function that handles allocation of patients within ISAs to arms

- lAddArgs:

  Further arguments used in fnAllocArm

- x:

  An object of class lAllocArm
