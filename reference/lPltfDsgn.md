# Platform Trial Design List

Platform Trial Design List of class lPltfDsgn

## Usage

``` r
new_lPltfDsgn(lFnDef = list(), lIntrDsgn = lIntrDsgn, ...)

validate_lPltfDsgn(x)

lPltfDsgn(lIntrDsgn, ...)
```

## Arguments

- lFnDef:

  Module containing function definitions

- lIntrDsgn:

  List of ISA designs

- ...:

  Additional platform-level modules

- x:

  An object of class lPltfDsgn

## Examples

``` r
if (FALSE) { # \dontrun{
# Internal module used by platform trial simulation
x <- lPltfDsgn()
} # }
```
