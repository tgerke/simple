# Runs a single platform trial simulation

Runs a single platform trial simulation

## Usage

``` r
fnRunSingleTrialSim(
  lPltfDsgn,
  bRetainSnaps = TRUE,
  bCreateLog = FALSE,
  cLogName = "platform"
)
```

## Arguments

- lPltfDsgn:

  Platform Design List

- bRetainSnaps:

  Whether or not to keep the list of snapshots; Default is TRUE

- bCreateLog:

  Whether or not to create a log file in current folder; Default is TRUE

- cLogName:

  Name of Log File; Default is "platform"
