# Summarize the platform trial

Functions for summarizing the platform trial of class lPltfSummary

## Usage

``` r
new_lPltfSummary(
  fnPltfSummary = function(lPltfTrial, lAddArgs) {
 },
  lAddArgs = list()
)

validate_lPltfSummary(x)

lPltfSummary()
```

## Arguments

- fnPltfSummary:

  Function which will check if Stop Rules are reached

- lAddArgs:

  Further arguments used in fnPltfSummary

- x:

  An object of class lPltfSummary

## Examples

``` r
if (FALSE) { # \dontrun{
# Internal module used by platform trial simulation
x <- lPltfSummary()
} # }
```
